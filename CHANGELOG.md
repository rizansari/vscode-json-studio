# Changelog

## 0.1.0

- Tree and table views with in-place editing that writes back to the file (undo, save and comments preserved).
- Beautify, minify, sort keys, and Repair JSON with a diff preview.
- Query and filter with text/regex, JSONPath, JMESPath and jq; filter the tree to matches; history and saved queries.
- Export results to a new tab, a JSON/CSV/YAML file, the clipboard, or back into the document.
- Transform toolkit, conversion to and from YAML/CSV/TSV/XML/TOML, type generation, JSON Schema inference and validation, semantic diff with JSON Patch export.
